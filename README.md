# อันนาสทีวี — เว็บไซต์ช่อง (Annas TV)

เว็บไซต์แบบ static (HTML/CSS/JS ล้วน ไม่ต้องติดตั้งอะไร ไม่ต้อง build) พร้อมขึ้น GitHub Pages ฟรี

**ฟีเจอร์**

- หน้าแรก + วิดีโอเด่นและวิดีโอล่าสุด ดึงจากช่อง YouTube อัตโนมัติ
- หมวดหมู่บทเรียน 8 หมวด (แก้ไข/เพิ่มได้ในไฟล์เดียว)
- ตารางถ่ายทอดสดรายสัปดาห์ (ไฮไลต์วันนี้ให้อัตโนมัติ)
- เวลาละหมาดประจำวัน เลือกจังหวัดได้ + แถบนับถอยหลังละหมาดถัดไป
- โหมดสว่าง/มืด รองรับมือถือเต็มรูปแบบ
- GitHub Action อัปเดตรายการวิดีโอให้ทุกวันเช้า 08:00 น.

---

## 1. โครงสร้างไฟล์

```
annas-tv/
├── index.html                 หน้าเว็บทั้งหมด
├── assets/
│   ├── css/style.css          สไตล์ทั้งหมด
│   ├── js/app.js              สคริปต์ทั้งหมด
│   └── img/                   favicon และรูปแชร์
├── data/
│   ├── site.json  ← แก้ตรงนี้เป็นหลัก (ลิงก์ช่อง หมวดหมู่ ตารางเวลา)
│   └── videos.json            รายการวิดีโอสำรอง (อัปเดตอัตโนมัติ)
├── .github/workflows/update-videos.yml
├── .nojekyll                  ห้ามลบ — บอก GitHub Pages ไม่ต้องประมวลผล Jekyll
└── robots.txt
```

**สิ่งที่ต้องแก้ก่อนขึ้นจริง** — เปิด `data/site.json` แล้วแก้:

| ช่อง | ความหมาย |
|---|---|
| `facebookUrl` | ใส่ลิงก์เพจ Facebook จริงของช่อง (ตอนนี้ยังเป็นลิงก์แฮชแท็กชั่วคราว) |
| `tiktokUrl`, `instagramUrl` | ใส่ลิงก์จริง หรือลบทิ้งถ้าไม่มี — ปุ่มจะหายไปเอง |
| `schedule` | เวลาออกอากาศจริงของแต่ละวัน |
| `categories[].playlistId` | ถ้ามี Playlist ใน YouTube ให้ใส่รหัส playlist (ขึ้นต้นด้วย `PL...`) จะลิงก์ตรงไปเพลย์ลิสต์นั้นแทนการค้นหา |

ไม่ต้องแตะ `index.html` เลยสำหรับการอัปเดตเนื้อหาปกติ

## 2. ขึ้น GitHub Pages (ฟรี) — ทำครั้งเดียว ~10 นาที

### ขั้นที่ 1 — สมัคร GitHub

ไปที่ https://github.com/signup สมัครด้วยอีเมล (ฟรี)

### ขั้นที่ 2 — สร้าง Repository

1. กดปุ่ม **+** มุมขวาบน → **New repository**
2. **Repository name:** `annas-tv`
3. เลือก **Public** (จำเป็น — GitHub Pages แบบฟรีต้องเป็น Public)
4. **อย่า** ติ๊ก "Add a README file"
5. กด **Create repository**

### ขั้นที่ 3 — อัปโหลดไฟล์

1. ในหน้า repository ที่เพิ่งสร้าง กด **uploading an existing file**
2. แตกไฟล์ `annas-tv.zip` ที่ได้รับ แล้วลาก **ไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างใน** (ไม่ใช่ตัวโฟลเดอร์ `annas-tv` เอง) มาวาง
3. รอจนอัปโหลดครบ แล้วกด **Commit changes**

> ⚠️ โฟลเดอร์ `.github` และไฟล์ `.nojekyll` ขึ้นต้นด้วยจุด บางเครื่องจะซ่อนไว้
> - **Windows:** File Explorer → แท็บ View → ติ๊ก "Hidden items"
> - **macOS:** กด `Cmd + Shift + .` ใน Finder

### ขั้นที่ 4 — เปิด GitHub Pages

1. ในหน้า repository กด **Settings** (แถบบน)
2. เมนูซ้าย กด **Pages**
3. หัวข้อ **Source** เลือก **Deploy from a branch**
4. **Branch:** เลือก `main` และโฟลเดอร์ `/ (root)` → กด **Save**
5. รอ 1–3 นาที แล้วรีเฟรชหน้า จะเห็นลิงก์เว็บขึ้นมา:

```
https://ชื่อผู้ใช้ของคุณ.github.io/annas-tv/
```

เว็บออนไลน์แล้ว 🎉

### ขั้นที่ 5 — เปิดสิทธิ์ให้ระบบอัปเดตวิดีโออัตโนมัติ

1. **Settings** → เมนูซ้าย **Actions** → **General**
2. เลื่อนลงหัวข้อ **Workflow permissions** → เลือก **Read and write permissions** → **Save**
3. ไปแท็บ **Actions** ด้านบน → เลือก **อัปเดตรายการวิดีโอจาก YouTube** → กด **Run workflow** เพื่อทดสอบครั้งแรก

จากนี้ระบบจะดึงวิดีโอใหม่ให้เองทุกเช้า

## 3. การแก้ไขเนื้อหาหลังเว็บขึ้นแล้ว

แก้ได้จากหน้าเว็บ GitHub โดยตรง ไม่ต้องลงโปรแกรม:

1. เข้า repository → เปิดโฟลเดอร์ `data` → คลิกไฟล์ `site.json`
2. กดไอคอน **ดินสอ ✏️** มุมขวาบน
3. แก้ข้อความ → เลื่อนลงล่าง กด **Commit changes**
4. รอ 1–2 นาที เว็บจะอัปเดตเอง

> ระวังเรื่องเครื่องหมาย `,` `"` `{` `}` ในไฟล์ JSON — ถ้าพิมพ์ผิดหน้าเว็บจะโหลดเนื้อหาไม่ขึ้น
> ตรวจสอบไฟล์ได้ฟรีที่ https://jsonlint.com ก่อน Commit

**ตัวอย่าง — เพิ่มรายการในตารางออกอากาศวันเสาร์:**

```json
{ "day": "เสาร์", "items": [
  { "time": "10:00", "title": "รายการครอบครัวมุสลิม", "host": "อ.อับดุลเลาะห์" },
  { "time": "20:00", "title": "ตอบปัญหาศาสนา", "host": "" }
] }
```

## 4. ใช้โดเมนของตัวเอง (ถ้าต้องการภายหลัง)

1. ซื้อโดเมน เช่น `annastv.com` (Namecheap, Cloudflare, GoDaddy ฯลฯ)
2. ที่ผู้ให้บริการโดเมน ตั้งค่า DNS:
   - `A` record ชี้ที่ `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - หรือ `CNAME` ของ `www` ชี้ที่ `ชื่อผู้ใช้.github.io`
3. GitHub → **Settings** → **Pages** → **Custom domain** ใส่โดเมน → **Save**
4. รอ DNS อัปเดต (ไม่กี่นาทีถึง 24 ชม.) แล้วติ๊ก **Enforce HTTPS**

## 5. ข้อควรรู้ทางเทคนิค

- **วิดีโอ** ดึงจาก RSS ของช่อง YouTube ผ่านบริการตัวกลาง หากตัวกลางล่ม ระบบจะใช้ `data/videos.json` แทนโดยอัตโนมัติ (ไฟล์นี้ GitHub Action อัปเดตให้ทุกวัน) จึงไม่มีทางที่หน้าเว็บจะว่างเปล่า
- **เวลาละหมาด** ใช้ AlAdhan API (ฟรี ไม่ต้องสมัคร) วิธีคำนวณ Muslim World League — เปลี่ยนวิธีคำนวณได้ที่ `prayer.method` ใน `site.json` (2 = ISNA, 3 = MWL, 4 = Umm al-Qura)
- **ไม่มีระบบหลังบ้าน ไม่มีฐานข้อมูล** จึงไม่มีค่าใช้จ่ายและไม่ต้องดูแลเซิร์ฟเวอร์
- เปิดในเครื่องเพื่อทดสอบ: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000
  (เปิดไฟล์ `index.html` ตรงๆ จะโหลด `data/*.json` ไม่ได้เพราะข้อจำกัดของเบราว์เซอร์)
